# Cinema Delight

A seed for making short films with an AI coding agent.

Your agent writes each scene as one HTML page drawn from a single clock, renders it frame by frame in headless Chromium, and finishes it with ffmpeg. You watch the drafts and leave notes. The agent does the rest.

It ships a method and the tools that run it. It ships no looks, no music and no footage. Your agent invents a look for each film, and you bring the sound: your own audio, or music your agent makes with whatever tools you have.

## Start

Give this repository to your agent and ask it for a film. It reads `AGENTS.md` first.

It needs Linux, Chromium or Chrome, ffmpeg, Node 22 or later, and Python 3.10 or later. Cleaning up and finishing audio needs Ardour.
